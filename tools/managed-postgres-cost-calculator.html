Managed Postgres Cost Calculator

A managed Postgres bill is instances plus storage plus billable backups. This example uses two Single-AZ db.m5.large PostgreSQL instances at $0.178 an hour for 730 hours, 100 GB of gp3 storage and 50 GB of billable backups, totaling $276.13. Rates and included backup allowances vary by provider, region and storage type.

Every result is pre-rendered with the default inputs, so the numbers are readable with JavaScript off. Results update as you type and nothing leaves your browser. Part of the Buildopsy engineering calculators.

Model limits: Defaults use editable US East (N. Virginia) Single-AZ PostgreSQL on-demand example rates. Platform presets only change the instance-hour rate. This sums entered instance-hours, storage and billable backup storage; it does not automatically model Multi-AZ topology, provisioned IOPS, I/O, data transfer, extended support, burstable CPU credits or account free-tier benefits. RDS backup allowance is shared by eligible backups in a Region. AWS RDS for PostgreSQL pricing.
