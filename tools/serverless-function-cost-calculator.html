Serverless Function Cost Calculator

Lambda bills requests plus GB-seconds of compute. This example prices 100 million requests at 200 ms and 512 MB at about $179.80 after the full monthly free tier. That free tier is shared across the AWS account; enter what remains after other functions.

Every result is pre-rendered with the default inputs, so the numbers are readable with JavaScript off. Results update as you type and nothing leaves your browser. Part of the Buildopsy engineering calculators.

Pricing scope: The default $0.20/million request rate and $0.0000166667/GB-second compute rate are an editable US East (N. Virginia) x86 on-demand example in the first duration tier. Use valid function settings: 128–10,240 MB memory and 1–900,000 ms billed duration. Compute rates vary by region, architecture and volume tier. Free requests and compute are monthly account-level allowances; enter the remaining amounts after all functions. Provisioned concurrency, response streaming, Lambda Managed Instances, ephemeral storage, logs and networking are excluded. AWS Lambda pricing.

Price a function from request volume, duration and memory, then subtract the remaining monthly account-level grants (defaults: one million requests and 400,000 GB-seconds).
