EC2 Compute Cost Calculator

EC2 charges for instance runtime, not CPU utilization. The example prices ten m5.large instances at an editable $0.096 per hour for 730 hours: $700.80 before discounts.

Every result is pre-rendered with the default inputs, so the numbers are readable with JavaScript off. Results update as you type and nothing leaves your browser. Part of the Buildopsy engineering calculators.

Billing note: AWS bills an instance while it is running, even when idle. Running time below models powered-on hours. The default $0.096/hour rate is a Linux m5.large example in US East (N. Virginia). The discount field is a sensitivity input, not a live Reserved Instance or Savings Plan quote. Actual rates depend on instance type, region and operating system. AWS instance billing states.
